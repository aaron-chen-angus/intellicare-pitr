# Artist's scrapbook edition

The visual direction is inspired by the illustration-led confidence, warm colour and uncluttered portfolio presentation of [Essi Kimpimäki's website](https://essillustration.com/). Its artwork and branding have not been copied. Rain & Me uses its own original paper-collage rain illustration, taped print mount, handwritten margin annotations, indexed notebook pages, berry-red actions and forest-green cover notes.

Titles use DM Serif Display, interface text uses DM Sans, and short handwritten notes use Caveat. The font files are included locally with their SIL Open Font Licenses in `public/fonts`; no Google Fonts connection is required in the deployed app. The original hero illustration was generated for this app and exported from managed storage into `public/scrapbook/rain-collage.webp` for standalone GitHub Pages delivery.

This is a visual-only change. Drawing, intake/consent, timer, restoration, analysis, scene/colour notes, timeline/replay, artistic restyling, provider scopes/free-only checks, original retention, downloads/share and gallery use the same code as before. New decoration stays outside drawing pixels and cannot enter the artwork exports. The lower-priority legacy cascade retains original responsive/functional rules, while the new styling has explicit high-contrast light/dark pairs.

Fonts and licenses: [DM Serif Display](https://fonts.google.com/specimen/DM+Serif+Display), [DM Sans](https://fonts.google.com/specimen/DM+Sans), [Caveat](https://fonts.google.com/specimen/Caveat), and the [Google Fonts source repository](https://github.com/google/fonts).
